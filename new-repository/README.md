# New Repository

This directory contains a fresh project scaffold. Initialize it as its own Git repository when you're ready:

```bash
git init
```

## Structure
- `README.md`: Project overview (this file).
- `src/`: Source code lives here.
- `tests/`: Test suite lives here.

## Getting Started
1. Initialize the repo with `git init`.
2. Add your project files under `src/`.
3. Add tests under `tests/`.
